# NWCompat

ISAT patches for Android

![siffrin](.github/assets/siffrin.webp)

Based on [chromori](https://github.com/fifomori/chromori)

## If you're looking for .apk, see [this](https://github.com/bbbreaddd/isat-androidd)

# Building (Powershell)

1. `pnpm i`
2. `$env:NWCOMPAT_DST="\path\to\isat-android"; .\build.bat`
